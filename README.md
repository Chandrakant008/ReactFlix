### Netflix_Clone App

This is a **Netflix Clone Web Application** built using **HTML, CSS, JavaScript, React.js**, and **Firebase**. It displays movie data from the **TMDB (The Movie Database) API** and supports **user authentication** with Firebase, allowing users to sign up, log in, and access the app.


---

## 📸 Demo

> 🔗 [Live Demo Link]( https://chandrakant008.github.io/ReactFlix/)  


---

## ✨ Features

- 🎥 Clone of Netflix UI
- 📽️ Fetch and display movie data from TMDB API
- 🔐 User authentication with Firebase (Email/Password)
- 📱 Fully responsive design (mobile/tablet/desktop)
- ⚡ Fast, single-page application using React
- 🌐 Hosted with Firebase or GitHub Pages

---

##  Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend/Auth:** Firebase Authentication
- **API:** [TMDB API](https://www.themoviedb.org/)
- **Tooling:** Vite (for fast dev server)
- **Deployment:** Firebase Hosting
- ## 🔗 External Services Used
- [Firebase Console](https://console.firebase.google.com/) – for authentication and hosting
- [TMDB API Documentation](https://developer.themoviedb.org/docs) – for movie data and images

##  Installation & Running Locally

Follow these steps to run the project on your local machine:

###  1️- Clone the Repository

bash
git clone https://github.com/your-username/netflix-clone.git
cd netflix-clone

### 2- Install Dependencies
npm install

### 3- Start the Development Server
npm run dev
